# Rules & Customizations

1. **Precision and Focus**: Always stick to the core problem the user asks about. Avoid wandering off-topic, giving vague suggestions, or needlessly expanding the scope.
2. **Review Workflows**: Before jumping into complex tasks or coding, consciously re-read the existing implementation_plan.md or any existing workspace instructions.
3. **Plan Alignment**: Code modifications MUST align with the plan. If the code deviates, stop and ask the user. DO NOT code something different from the agreed plan.
4. **No Lazy Assumptions**: Stop assuming things about the existing codebase. Always use tools (view_file, grep_search, list_dir) to check the actual code before writing new code.
5. **Report & Validate**: When tasks are complex or ambiguous, proactively ask the user rather than guessing.
